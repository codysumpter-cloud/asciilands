# Source placement and licensing

`codysumpter-cloud/asciilands` contained a standalone experimental PHP action RPG before this import. Its root `README.md`, GPLv3 `LICENSE.txt`, maps and game logic are preserved.

The new `glyphbound/` folder is an **independently implemented** 3D-ASCII survival prototype with a separate `glyphbound/LICENSE` (MIT) and optional Cloudflare guest-room server. It is not a renamed copy of the original PHP game, nor a port of Asciicker's MIT-licensed C++ renderer. If using the original Asciicker engine later, include its unmodified LICENSE and attribute it separately.

No proprietary Asciilands gameplay source or artwork was added.
